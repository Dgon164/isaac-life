Owner's laws from the 2026-07-03 night design conversation, all implemented same-session (paperclip 3c17c3b, both repos pushed):

1. **"Knowing what is right is intelligence. Knowing what is wrong is wisdom."** Junk/refuted structures are the SAME species — detected error — and they are a *classification*, not garbage: kept in a wrong section with the WHY attached, so error itself is learnable material. Never prevent, never delete. (Engine: `_crystallize` Phase 3.5 — every type tested vs its chance-null [degree-preserving shuffle, best-of-chance, selection-corrected]; failures → `isaac.wrong_types` + node meta `verdict: wrong`, `why_wrong`. C3: 249/249 chance types filed with reasons; category types all sound.)

2. **Deprecation = supersession.** "If there is a and b, and b works better, use b" — and A is KEPT wearing its defeat (what was believed, what beat it, by how much). (Engine: confirm() OVERTURN appends the loser to `superseded` with why. C6: defeated parabola preserved with "overturned by rival 'cosine', SSE 3.198 vs 1253".)

3. **No optimizing before limits.** "We have yet to run into processing/memory/structural limitations... we fell into that trap before by telling it what was important and not and it broke everything." → NO salience weighting, NO pruning, NO importance-telling, NO premature perf work. Measure knees (C5: ~420 s @ 800 nodes, known, deliberately untouched); optimize only when a real limit bites.

4. **No human-style forgetting.** Isaac doesn't share the mammal resource constraint; disuse-deletion is epistemically lossy and would surrender the no-catastrophic-forgetting differentiator. "Everything enters, nothing leaves" stands. The legitimate removals are evidence-based only (wrong-classification, supersession), always with provenance.

5. **Occam is a preference, not a gate.** "Simpler with the same accuracy or better is better" is a heuristic for choosing what to USE — "its not only. its just preferred." Accuracy decides; ties prefer simpler; the non-preferred candidate is RETAINED (alternatives list) — nothing is rejected into nothing. (Engine: refine()'s acceptance semantics, d98597c.)

**Why:** these came as corrections to my proposals (admission-gate-that-refuses-formation; forgetting/salience ecology) — his versions were better and more coherent with the existing theory (ledger negative-knowledge, rivals, don't-destroy-information). **How to apply:** when designing retention/cleanup/optimization anywhere in Isaac, default to classify-don't-delete, supersede-don't-overwrite, and wait for a measured limit before optimizing.
