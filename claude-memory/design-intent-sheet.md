**Owner, 2026-07-05:** "all of these things that exist and have been meant
to be implemented as the basic concepts seem to be getting overlooked...
I have to manually go back and insert all of the things that I just
assumed were being carried over." He mandated a per-chat reference sheet.

**The sheet lives at `isaac-paperclip/docs/DESIGN_INTENT.md`** (copy at
isaac_project root). READ IT AT SESSION START and BEFORE ANY NEW BUILD.

**THE LAW ABOVE THE CHECKLIST (owner, 2026-07-05): "There is no
separation. Everything is all mixed together. There is no different
thing. Everything should always be universally applied if it can."**
No mechanism is domain-siloed — when building or testing anything, ask
where else it applies RIGHT NOW, then apply it (the readout was filed
as a glyph tool; applied to covtype it gained +11.4 the same hour).

The reuse checklist (condensed — full version in the sheet):
1. Which existing organ already does this?
2. New evidence doors onto EXISTING nodes — never a parallel system.
3. Measured, not hand-told (thresholds→tests, weights→calibration).
4. **KEEP every measurement** computed for a gate (spreads, residuals,
   bars) — it is knowledge on the node. (The bone-normals lesson: the
   engine computed each part's normal, used it once, threw it away, and
   the owner had to re-design his own design.)
5. Null on everything; expand freely, compress by test.
6. Wrong kept + classified; supersession; losers wear defeat.
7. Hierarchy: variants/styles/senses are real things under parents —
   never smush by averaging.
8. Negatives first-class: certified nevers VETO ("this or this, never
   that").
9. Identity = relations/ratios/rel-angles; pose reported separately.
10. Output = rank + veto + abstention; complete numbers only.

**Why:** each session rebuilds from result-focused handoffs; the owner's
standing designs were scattered across memories/manual/conversation, so
minimal-first builds kept discarding already-settled intent.
**How to apply:** at session start, read the sheet; before ANY mechanism,
walk the checklist; when the owner describes a design, add it to the
sheet in the same step (same-step rule, like the manual).
