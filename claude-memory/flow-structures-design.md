The design (full text on the sheet, DESIGN_INTENT.md):
- three missing things behind every unused tool: PRESENCE (no node),
  CONSIDERATION (no scan, no trace of unuse), ADAPTATION (no branch)
- flows = net content, own namespace (flow:/step: nodes), read by the
  KERNEL LOOP — the interpreter segment's true shape
- **THE CONSIDERATION LAW: every registered step fires or is bypassed
  WITH A RECEIPT — silent unconsideration outlawed**
- steps face word-style ELECTIONS ([[self-learning-is-the-goal]]);
  the commonality miner names where a flow keeps losing → **branching
  = piecewise supersession at the flow level**
- REGISTRATION RULE standing: every new tool ships WITH its flow node
  (when-tags); unregistered = visible defect
- first build: one real pipeline (drill session or audit face) as
  flow nodes + walker + bypass receipts + one evidence-driven branch

**Why:** this is the project's oldest wound named at Isaac's level —
the sheet itself exists because settled designs kept being silently
dropped ([[design-intent-sheet]]); the reach audit measured it in him
(engine stateless, caller decides everything, 15 answer roads with no
router). [[isaac-kernel-loop-design]]
**How to apply:** never add a capability as a bare function again —
it registers when-tags or its absence is called out; the interpreter
segment's loop work should be built AS the flow executor.
